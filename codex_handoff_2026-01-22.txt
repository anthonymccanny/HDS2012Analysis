ACS formulas currently implemented (acs_merging.R)
- poverty_rate = poverty_belowE / poverty_totalE (B17001)
- college_graduate_rate = (education_bachelorsE + education_mastersE + education_professionalE + education_doctorateE) / education_totalE (B15003)
- high_skilled_rate = (occupation_mgmt_maleE + occupation_mgmt_femaleE) / occupation_totalE (C24010)
- single_parent_rate = (single_parent_maleE + single_parent_femaleE) / total_householdsE (B11001)
- ownership_rate = tenure_ownedE / tenure_totalE (B25003)
- percent_white = race_white_aloneE / race_totalE (B03002)
- percent_black = race_black_aloneE / race_totalE
- percent_asian = race_asian_aloneE / race_totalE
- percent_hispanic = race_hispanicE / race_totalE

Note: These are tract-level in acs_merging.R (2008–2012 5-year). If you need block-group level instead, change geography to "block group" and adjust GEOIDs. These can be used to replace C&T vars in analysis.R (e.g., w2012pc_Rec ⇢ percent_white, povrate_Rec ⇢ poverty_rate, skill_Rec ⇢ high_skilled_rate, college_Rec ⇢ college_graduate_rate, ownerocc_Rec ⇢ ownership_rate, singlefamily_Rec ⇢ single_parent_rate or a different ACS definition if you want true single-family share).
